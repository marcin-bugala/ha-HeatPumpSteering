# HA HeatPumpSteering

Docelowa customowa integracja do Home Assistant do sterowania ogrzewaniem pompą ciepła z uwzględnieniem komfortu na kondygnacjach.

Gałąź `main` jest punktem wyjścia do osobnego rozwoju gotowego produktu. Implementacja docelowej integracji nie została jeszcze dodana.

Aktualny prototyp, jego automatyzacje, moduł historii, dashboard, testy i dokumentacja są zachowane na gałęzi [poc/co1-automation](https://github.com/marcin-bugala/ha-HeatPumpSteering/tree/poc/co1-automation). Dalsze zmiany prototypu należy prowadzić na tej gałęzi.
